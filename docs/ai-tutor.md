# AI Tutor Future

The MVP keeps all execution local and backend-free. Future tutor features should answer questions from trace events instead of guessing from free text.

Initial questions:

- Why did this thread stall?
- Why was there divergence?
- How can I optimize this kernel?

Tutor answers should cite the active cycle, thread, instruction, component, hazard reason, register diff, memory diff, and relevant glossary term.
